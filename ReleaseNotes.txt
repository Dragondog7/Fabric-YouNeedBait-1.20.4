 ## Fabric 0.4.0
 ### New
 Fish Weights
 * Adds configuration options for weights for each fish caught
 * Can be displayed in lb or kg
 * Fish weight bias setting that allows configuration of the rarity of record size fish
 * Only works with custom fish
 * Each species has a custom weight range

 Configuration File
 * There is a new file for custom configuration. config/youneedbait.toml
 * These are the initial settings
 	* Whether bait is required. Default: true (i.e., "Y")
 		*	bait_required = true
 	* Percentage chance of bait being consumed per use (0..100). Default: 10
 		* bait_usage_percent = 10
 	* Fish weight units
 		* 	weight_unit = "lb"
 	* Enable fish weights
 		* weighted_fish_enabled = true
 	* Fish weight bias. Larger number means harder to catch huge fish
 		* fish_weight_bias = 1.0		*

 ### Master Fisherman Villager
 We've significantly expanded and improved the Master Fisherman villager's trade offerings, providing a more engaging and progressive experience for all aspiring anglers! The "Fancy Fishing Rod" is now more accessible through a clear trade progression. It now requires a Minnow Bucket to obtain the villager instead of a Salt Block
 #### **Trade Summary by Level:**

 **Level 1: Novice Fisherman**

 -   **Sell:** 16x Worms for 1x Emerald
 -   **Buy:** 2x Emeralds for 8x Caterpillars
 -   **Buy:** 3x Emeralds for 1x Fillet Knife

 **Level 2: Apprentice Fisherman**

 -   **Sell:** 8x Minnows for 1x Emerald
 -   **Buy:** 3x Emeralds for 6x Leeches
 -   **Buy:** 5x Emeralds for 1x Hook

 **Level 3: Journeyman Fisherman**

 -   **Sell:** 10x Cod for 1x Emerald

 -   **Buy:** 8x Emeralds for 1x Can of Worms

 **Level 4: Expert Fisherman**

 -   **Sell:** 6x Sucker Minnows for 2x Emeralds
 -   **Sell:** 8x Salmon for 1x Emerald
 -   **Buy:** 3x Emeralds for 12x Salt
 -   **Buy:** 12x Emeralds for 1x Fishing Rod (Vanilla)

 **Level 5: Master Fisherman**

 -   **Sell:** 6x Tropical Fish for 2x Emeralds
